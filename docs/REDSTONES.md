# 💎 List of Red Gemstones & Minerals

A reference guide for red gemstones, minerals, and their inspiration in the **Spinel** (`spinel.md`) project.

---

## 🔴 Primary & Pure Red Gemstones

| Gemstone | Mineral Variety / Formula | Description & Characteristics | `.md` Domain Status |
| :--- | :--- | :--- | :--- |
| **Spinel** | $\text{MgAl}_2\text{O}_4$ (Magnesium Aluminium Oxide) | Brilliant crimson-to-ruby red gemstone with extreme durability (Mohs 8) and cubic crystal symmetry. Famous historical gems (e.g. *Black Prince's Ruby*) are actually Spinels. | **AVAILABLE** (`spinel.md`) ⭐ *Chosen* |
| **Ruby** | $\text{Al}_2\text{O}_3\text{:Cr}$ (Corundum) | The classic king of red gemstones, colored by chromium ions. | Taken (`ruby.md`) |
| **Corundum** | $\text{Al}_2\text{O}_3$ (Aluminium Oxide) | The parent mineral species of both Ruby and Sapphire. Ultra-hard (Mohs 9), resilient, and structural. | **AVAILABLE** (`corundum.md`) |
| **Garnet** | Silicate Group ($\text{X}_3\text{Y}_2(\text{SiO}_4)_3$) | Deep fiery wine-red crystal, timeless and resilient. | Taken (`garnet.md`) |
| **Pyrope** | $\text{Mg}_3\text{Al}_2(\text{SiO}_4)_3$ | Blood-red garnet named from ancient Greek *pyrōpós* ("fire-eyed"). High clarity and refractive index. | **AVAILABLE** (`pyrope.md`) |
| **Almandine** | $\text{Fe}^{2+}_3\text{Al}_2(\text{SiO}_4)_3$ | Deep red with violet undertones; the classic widespread garnet. | **AVAILABLE** (`almandine.md`) |
| **Rhodolite** | Pyrope-Almandine blend | Lustrous raspberry-to-rose red garnet crystal. | **AVAILABLE** (`rhodolite.md`) |
| **Spessartine** | $\text{Mn}_3\text{Al}_2(\text{SiO}_4)_3$ | Fiery mandarin-to-deep red garnet. | **AVAILABLE** (`spessartine.md`) |
| **Bixbite (Red Beryl)** | $\text{Be}_3\text{Al}_2(\text{SiO}_3)_6\text{:Mn}$ | Ultra-rare vivid red beryl known as the "Red Emerald", found in Utah. | **AVAILABLE** (`bixbite.md`) |
| **Pezzottaite (Raspberyl)** | $\text{Cs}(\text{Be}_2\text{Li})\text{Al}_2\text{Si}_6\text{O}_{18}$ | "Raspberry Beryl", rare cesium-rich raspberry-red gem named after Italian mineralogist Federico Pezzotta. Catchy synonym: **Raspberyl** (evoking Raspberry Pi!). | **AVAILABLE** (`raspberyl.md` ⭐ / `pezzotta.md`) 🇮🇹 🍓 |
| **Taaffeite** | $\text{BeMgAl}_4\text{O}_8$ | Famous ultra-rare gemstone originally discovered already faceted and mistaken for Spinel! | **AVAILABLE** (`taaffeite.md`) |
| **Rubellite** | Red Tourmaline ($\text{Na}(\text{Li},\text{Al})_3\text{Al}_6\dots$) | Vivid pink-to-deep ruby red elbaite tourmaline. | **AVAILABLE** (`rubellite.md`) |
| **Carnelian** | $\text{SiO}_2$ (Chalcedony) | Fiery translucent red-orange quartz, historical stone of scribes and signet wax seals. | **AVAILABLE** (`carnelian.md`) |
| **Cinnabar** | $\text{HgS}$ (Mercury Sulfide) | Brilliant brick-red mineral, source of the vermilion pigment. | **AVAILABLE** (`cinnabar.md`) |
| **Realgar** | $\text{As}_4\text{S}_4$ | "Ruby Sulfur" — ancient bright red arsenic sulfide crystal. | **AVAILABLE** (`realgar.md`) |
| **Vanadinite** | $\text{Pb}_5(\text{VO}_4)_3\text{Cl}$ | Bright hexagonal ruby-red to scarlet crystals with high luster. | **AVAILABLE** (`vanadinite.md`) |
| **Crocoite** | $\text{PbCrO}_4$ (Lead Chromate) | Saffron-to-hyacinth red crystalline mineral with needle-like prisms. | **AVAILABLE** (`crocoite.md`) |
| **Proustite** | $\text{Ag}_3\text{AsS}_3$ | "Ruby Silver" — vivid scarlet-red sulfosalt crystal. | **AVAILABLE** (`proustite.md`) |
| **Cuprite** | $\text{Cu}_2\text{O}$ (Copper Oxide) | Dark cochineal-red mineral with metallic adamantine luster. | **AVAILABLE** (`cuprite.md`) |
| **Rhodonite** | $(\text{Mn}^{2+},\text{Fe},\text{Mg})\text{SiO}_3$ | Rose-red to brownish-red manganese inosilicate with black dendritic veins. | **AVAILABLE** (`rhodonite.md`) |
| **Rhodochrosite** | $\text{MnCO}_3$ (Manganese Carbonate) | "Inca Rose" — vivid raspberry-to-rose red crystal. | **AVAILABLE** (`rhodochrosite.md`) |
| **Red Zircon (Hyacinth)** | $\text{ZrSiO}_4$ | Ancient fiery red gemstone with diamond-like luster. | **AVAILABLE** (`hyacinth.md`) |

## 🎨 Red & Multicolor Varieties

| Gemstone | Color Expression & Notes |
| :--- | :--- |
| **Red Diamond** | The rarest of all fancy-colored diamonds. |
| **Padparadscha** | Rare, prized lotus-blossom pinkish-orange corundum. |
| **Painite** | Ultra-rare borate mineral, deep ruby-red to brownish-red. |
| **Tugtupite** | "Reindeer Stone", tenebrescent deep crimson cyclosilicate. |
| **Clinohumite** | Rare glowing fiery orange-red silicate gemstone. |
| **Red Coral** | Precious organic red marine skeleton (*Corallium rubrum*). |
| **Red Fluorite** | Rare octahedral crimson crystal with high fluorescence. |
| **Red Jade** | Vivid reddish nephrite/jadeite associated with passion and vitality. |
| **Red Quartz (Hematoid Quartz)** | Quartz crystals containing red hematite / iron inclusions. |
| **Red Sunstone** | Feldspar mineral with sparkling red-copper aventurescence. |
| **Red Jasper** | Opaque microcrystalline quartz colored deep brick-red by iron oxide. |
| **Red Labradorite (Spectrolite)** | Feldspar exhibiting fiery iridescent red flashes. |
| **Sardonyx / Red Onyx** | Layered chalcedony with alternating bands of red sard and white quartz. |
| **Red Tiger's Eye (Dragon's Eye)** | Heat-treated golden tiger's eye shifting to rich chatoyant red. |
| **Red Fire Opal** | Translucent to transparent opal with fiery red-orange body color. |
| **Red Apatite** | Rare reddish phosphate crystal. |
| **Red Topaz (Imperial Topaz)** | Rare fiery peach-to-deep red silicate gemstone. |
| **Eudialyte** | Complex red cyclosilicate mineral often found in alkaline igneous rocks. |
| **Andalusite** | Pleochroic olive to fiery red-brown metamorphic mineral. |
