# Markdown Cheatsheet

Here are the supported core formatting blocks:
- **Bold text** with double asterisks
- *Italic text* with single asterisks
- <u>Underlined text</u>
- Unordered lists (`-` or `*`)
- Ordered lists (`1.`)
- Checkboxes (`- [ ]` or `- [x]`)
